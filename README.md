# 泥win助手

一个面向温州大学学生的 Flutter Android 课表与作业随记应用。产品思路参考 WakeUp、拾光课程表等产品，但代码与视觉资产在本仓库中重新实现。

## 已实现

- Material You：完整 Material 3 组件、Android 12+ 壁纸动态取色、深浅模式和备用主题色。
- 四栏首页：今日课程、整周课表、作业与随记、“我的”设置。
- 多学期管理：每个学期保存独立的名称、第一周、总周数和课程，可快速切换、新建、编辑或删除。
- 一周课表：默认启动可选“课表/今日”，按当前学期周数切换、左右滑周、今天高亮、单双周和周末课程；默认自动压缩 13 节以减少滚动。
- 临时调课：课表页开启“调整当前周”后，可点空格临时添加；课程支持本周停课、恢复、仅本周修改和整学期编辑/删除。课表以“临/改/删/单/双/非”标签区分状态，停课与非本周课程灰显。
- 作业随记：快捷关联已有课程或创建自定义随记，支持截止时间、完成状态和提醒开关。
- 自定义字体：应用不内置第三方字体，支持从本机导入霞鹜文楷等 `.ttf` 文件并随时恢复系统字体。
- 手动教务导入：内置浏览器提供地址栏、返回、前进、刷新和主页，不自动点击或跳转网页。
- 正方课表解析：新版优先读取同源结构化课表接口，失败后再用支持 `rowspan/colspan` 的 DOM 矩阵解析；缺少明确星期、节次或周次的数据不会猜测导入。
- 导入预览：写入前展示识别结果并确认当前周；再次同步只替换温大来源课程，保留手动课程。
- 自定义作息：内置用户指定的 13 节预设，每节起止时间均可修改。
- 自定义外观：背景图片、背景透明度、液态玻璃、课表高度、课程块宽度间距、圆角、透明度和字体大小。
- 课程显示：节次栏同时标明上课/下课时间；地点可隐藏；课程支持“水”等最多 4 字的自定义角标。
- 快速添加：点击课表中的星期与节次格子，直接按该位置创建课程。
- Android 本地通知：课程与待办分配独立调度容量，串行防重入；支持精确闹钟并在权限不足时自动降级，可在设置中测试并查看实际登记数量。
- 系统日历：经用户确认后，将当前学期的有效课程、地点和课前提醒写入 Android 日历；不会写入作业。
- 杂物：内置可编辑选项的选择困难转盘、多组吃饭预设和自动启动计数。
- 彩蛋：每次冷启动随机选择一条文本；开关收在“我的 → 杂物 → 其他”。
- 快捷网页：“我的”顶部可保存常用网页，内置 WebVPN 直达输入框、地址栏、外部浏览器和电脑模式切换。
- 倒计时与统计：今日页支持日期倒计时，作业页显示完成率；微信读书统计作为实验功能按需开启。
- 可选实验功能：操作时间线、按培养方案接口读取学生学业情况、应用内登录并控制趣智热水，以及只同步课表数据的 WebDAV 备份。
- 本地备份：一键导出/恢复 JSON，包含全部学期及其课程、作业、作息与倒计时。
- 启动优化：稳定加载本地课表后立即显示首屏，通知调度移到首帧之后；业务数据变化不再重建整个 MaterialApp；背景图片限制解码尺寸并移除全屏实时模糊。
- 隐私：不注入或读取学校密码字段，不保存学校账号密码；业务数据默认仅在本机，只有用户主动使用 WebDAV 时才上传课表数据。

## 温大同步流程

1. 在“我的”中打开“导入温大课表”。
2. 在学校统一身份认证页面自行登录；验证码或二次认证由学校页面处理。
3. 使用网页本身的入口手动打开“新教务系统 → 信息查询 → 个人课表”。
4. 选择学期并查询后，点击右上角“提取”。
5. 检查预览，选择当前教学周并确认导入。

应用不会自动点击链接、提交表单或改变网页地址，也不会绕过学校认证。

## 微信读书实验功能

API Key 使用系统加密存储，不写入 JSON 备份。阅读统计通过微信读书 Agent API 获取并缓存 6 小时；进入“我的 → 实验性功能”后才会启用，“我的”页面仅在开启时显示阅读摘要。

## 实验性同步与洗澡

- WebDAV 使用用户填写的 HTTPS 文件地址，凭据保存在 Android 系统安全存储中；上传内容严格限制为学期、课程和作息时间。
- 洗澡功能在应用内完成登录、附近设备扫描和启停。趣智会话、已保存设备和活动订单使用系统安全存储，退出账号时清除。
- 学业情况在用户自行登录教务系统后，读取培养方案分类及各分类课程接口并在本地整理显示，不保存教务账号密码。
